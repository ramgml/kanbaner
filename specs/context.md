# Контекст проекта

Дата фиксации: 2026-11-06.

Kanbaner — локальная однопользовательская система управления задачами и заметками с адаптивным веб-интерфейсом.

Система строится как минимальное plugin-ядро. Задачи, канбан, список, заметки, поиск и интеграции являются плагинами и используют один публичный контракт. Встроенного ИИ-ассистента нет: внешние агенты при необходимости подключаются к HTTP API через необязательный MCP-адаптер.

## Принятые рамки

- Регистрации и пользовательских аккаунтов нет.
- Приложение предназначено для запуска на localhost или в доверенной локальной сети.
- Основное хранилище — SQLite в режиме WAL.
- Storage backend подключается как провайдер; доменные плагины не зависят от SQLite.
- Внешний сервер БД, Docker и TCP-порт не используются.
- Поддерживаемые ОС MVP: Linux и Windows.
- Плагины считаются доверенным локальным кодом; жёсткая песочница в MVP не предусмотрена.
- Новые функции должны добавляться через Plugin SDK и контракт без изменения ядра.
- MCP не является частью ядра и не содержит доменной логики.
