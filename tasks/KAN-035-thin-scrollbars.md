# KAN-035 — Тонкие кроссбраузерные скроллбары

## Цель

Сделать системные скроллбары тоньше и визуально согласованными во всех
поддерживаемых браузерах без замены нативной прокрутки.

## Результат

- Современные браузеры используют стандартные `scrollbar-width: thin` и
  `scrollbar-color`.
- Старые WebKit-браузеры получают CSS-fallback шириной 8 px.
- Цвет ползунка следует light/dark теме, track прозрачный.
- Прокрутка колесом, клавиатурой, touch и drag остаётся нативной; зависимости и
  JavaScript-обёртки не добавляются.

## Объём работ

- [x] Добавить глобальные стили скроллбаров.
- [x] Проверить computed styles на странице и вложенной колонке в обеих темах.
- [x] Прогнать проверки и production E2E.
- [x] Обновить документацию и создать отчёт без коммита.

## Владение файлами

- `apps/web/src/app/globals.css`;
- `apps/web/e2e/**` — проверка скроллбаров и атомарная синхронизация modal helpers;
- `README.md` — текущее состояние интерфейса;
- `tasks/KAN-035-thin-scrollbars.md`, `tasks/reports/KAN-035.md`.

Запрещено: менять DOM плагинов, overflow/layout, доменные контракты и добавлять
scrollbar-библиотеки.

## Критерии приёмки

- [x] Страница и вложенные прокручиваемые области используют тонкий скроллбар.
- [x] Light/dark цвета вычисляются из существующих темных токенов.
- [x] Mobile overflow и нативная прокрутка не ломаются.
- [x] Проверки зелёные.
