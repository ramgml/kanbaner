# KAN-037 — Notion-подобный плагин заметок

## Цель

Добавить независимый `kanbaner.notes` с визуальным Markdown-редактором,
иерархией страниц, поиском, локальными изображениями и универсальными связями.

## Результат

- Визуальный CommonMark/GFM редактор с toolbar/slash-действиями и
  автосохранением через версионированные команды.
- Дерево страниц с созданием вложенных заметок, reorder/move, breadcrumbs и
  защитой от циклов.
- Избранное и недавно открытые страницы без увеличения версии содержимого.
- Полнотекстовый поиск с полной переиндексацией.
- Самостоятельные заметки и связи с проектами/задачами через `ResourceRef`.
- Локальные растровые изображения, экспорт самодостаточного `.md`.
- Каскадное удаление ветки только после подтверждения с количеством страниц.
- Desktop/mobile, клавиатурные альтернативы DnD, light/dark темы.

## Объём работ

- [x] Создать package, client-safe контракт, доменный Store и операции.
- [x] Зарегистрировать ресурсы, события, поиск и связи без зависимости от tasks.
- [x] Подключить composition и независимый `/view/notes`.
- [x] Реализовать визуальный редактор и надёжное автосохранение.
- [x] Реализовать дерево, избранное, недавние и поиск.
- [x] Реализовать вложения, экспорт и переходы по связям.
- [x] Добавить панель связанных заметок через публичный UI-slot, без импорта
  чужого плагина.
- [x] Покрыть доменные/component/E2E проверки и обновить документацию.

## Владение файлами

- `packages/plugin-notes/**`, `packages/markdown-ui/**`;
- общий Markdown renderer из `packages/plugin-projects` и его импорты;
- composition/build/import boundaries и необходимые UI runtime-точки;
- `apps/web/e2e/notes.spec.ts` и production composition;
- `specs/*` по фактически принятым решениям;
- `README.md`, README затронутых пакетов;
- `tasks/KAN-037-notion-notes-plugin.md`, `tasks/reports/KAN-037.md`.

Запрещено: зависимость notes от tasks/kernel/SQL, прямые импорты UI плагинов
друг друга, raw HTML, небезопасные URL, скрытое удаление данных, журналирование
содержимого и встроенный ИИ.

## Критерии приёмки

- [x] Визуально созданная и отредактированная заметка сохраняется после reload.
- [x] Дерево сохраняет parent/position, не допускает циклов и доступно без DnD.
- [x] Favorite/recent не меняют версию заметки; поиск работает на кириллице.
- [x] Конфликт версий не перезаписывает локальный черновик.
- [x] Изображения переживают reload и попадают в экспорт `.md`.
- [x] Удалённый ресурс не оставляет рабочей ссылки; notes работает без tasks.
- [x] Полные проверки и production build зелёные.
