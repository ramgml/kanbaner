# KAN-043 — Увеличить место для названий в дереве заметок

## Цель

Названия страниц обрезаются слишком сильно, потому что скрытые до hover кнопки действий всё равно занимают ширину строки.

## Результат

В обычном состоянии название использует доступную ширину sidebar. Действия остаются доступными с клавиатуры и на touch, не ломая раскладку.

## Объём работ

- [ ] Убрать действия из нормального горизонтального расчёта ширины, например через аккуратный overlay с читаемым фоном.
- [ ] Сохранить expand, select, favorite, reorder/create/delete и keyboard/touch доступность.
- [ ] Добавить проверку длинных названий и mobile 360.

## Владение файлами

Разрешено:
- `packages/plugin-notes/src/ui/note-tree.tsx` и `note-tree.test.tsx`;
- `apps/web/e2e/notes.spec.ts`;
- `tasks/reports/KAN-043.md`.

Запрещено:
- домен, команды, другие UI-плагины и редактор.

## Критерии приёмки

- [ ] Скрытые действия не уменьшают ширину названия.
- [ ] Длинное название получает существенно больше места и корректно обрезается только при нехватке ширины.
- [ ] Действия доступны с клавиатуры и на мобильном, нет overflow.
- [ ] Проверки зелёные.
