# KAN-043 — Увеличить место для названий в дереве заметок

## Цель

Названия страниц обрезаются слишком сильно, потому что скрытые до hover кнопки действий всё равно занимают ширину строки.

## Результат

В обычном состоянии название использует доступную ширину sidebar. Действия остаются доступными с клавиатуры и на touch, не ломая раскладку.

## Объём работ

- [x] Убрать действия из нормального горизонтального расчёта ширины, например через аккуратный overlay с читаемым фоном.
- [x] Сохранить expand, select, favorite, reorder/create/delete и keyboard/touch доступность.
- [x] Добавить проверку длинных названий и mobile 360.

## Критерии приёмки

- [x] Скрытые действия не уменьшают ширину названия.
- [x] Длинное название получает существенно больше места и корректно обрезается только при нехватке ширины.
- [x] Действия доступны с клавиатуры и на мобильном, нет overflow.
- [x] Проверки зелёные.
