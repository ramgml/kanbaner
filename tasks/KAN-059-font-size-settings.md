# KAN-059 — Глобальный размер шрифта в настройках

## Цель

Позволить пользователю уменьшать или увеличивать интерфейс под конкретный монитор
без изменения системного масштаба ОС.

## Решение

- В `/settings` в карточке «Оформление» добавить select `90% / 100% / 110% / 125%`.
- По умолчанию использовать 100%; применять выбор сразу через root font-size.
- Сохранять значение в `localStorage` и восстанавливать до отрисовки, чтобы не
  было вспышки прежнего размера.
- При недоступном или повреждённом хранилище использовать 100%, не блокировать UI.
- Не добавлять зависимости, серверные настройки или аккаунт.

## Критерии приёмки

- [x] Размер применяется глобально и сохраняется после reload/navigation.
- [x] Select доступен клавиатурой и имеет понятный accessible name.
- [x] Невалидное значение и недоступный localStorage безопасно дают fallback.
- [x] Desktop/mobile не получают новый horizontal overflow.
- [x] Unit/E2E и полный `pnpm check` зелёные.
