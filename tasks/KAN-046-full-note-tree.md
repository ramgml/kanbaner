# KAN-046 — Полноценное дерево заметок с переносом во вложенные

## Цель

Сейчас иерархия создаётся через «+» и выбор родителя, а drag-and-drop меняет только порядок среди siblings. Сделать визуальное и поведенческое дерево, в котором страницу можно перенести на другую как вложенную.

## Результат

Пользователь видит иерархию, раскрывает ветки, переносит страницу на родителя или между siblings и выполняет те же операции без drag-and-drop. Существующие ограничения `note.move` на циклы и глубину сохраняются.

## Объём работ

- [x] Разделить drop-сценарии: перенос на узел как child, перед/после узла как sibling и в корень.
- [x] Добавить понятный drop indicator: внутрь, выше, ниже, корневая зона; не полагаться только на цвет.
- [x] Раскрывать target при переносе внутрь и показывать вложенность через отступы/соединительные элементы без лишней ширины.
- [x] Сохранить и улучшить expand/collapse, состояние выбранной страницы и раскрытие её предков.
- [x] Сохранить кнопки reorder/create/delete и parent selector как доступную альтернативу DnD.
- [x] Не применять tree-визуализацию к плоским режимам «Недавние» и результаты поиска.
- [x] Добавить unit/integration/E2E для child, sibling, root, циклов и keyboard/mobile.

## Контракты и зависимости

- Использовать существующий `kanbaner.notes.note.move` с `expectedVersion`, `parentId` и `position`.
- Домен уже запрещает циклы и чрезмерную глубину; UI должен показывать ошибку без оптимистичного расхождения с сервером.
- Начинать после завершения KAN-044 и KAN-045, поскольку файлы пересекаются.

## Критерии приёмки

- [x] Drop на страницу делает dragged её child с корректной позицией.
- [x] Drop выше/ниже меняет sibling order, drop в корень убирает parentId.
- [x] Циклы и превышение глубины не допускаются и понятно отображаются.
- [x] После переноса сохраняются версии затронутых заметок, selection и предсказуемое раскрытие.
- [x] Все операции доступны без DnD и на mobile 360.
- [x] Проверки зелёные, существующие сценарии заметок не регрессировали.

## Риски

- Неоднозначность drop между «внутрь» и «рядом» снижается зонами и preview.
- Перенос меняет версии соседей; обновление открытой заметки не должно затирать черновик.
- Вложенные overlay-действия не должны возвращать избыточные отступы KAN-045.
