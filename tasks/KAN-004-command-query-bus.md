# KAN-004 — Шина команд и запросов

## Цель

Реализовать единый типизированный механизм регистрации и выполнения команд и запросов с валидацией, контекстом и стандартными ошибками.

## Результат

Плагин регистрирует mutation или query, а ядро проверяет уникальность ID, вход, выход и возвращает единый конверт результата.

## Объём работ

- [ ] Реализовать реестр команд.
- [ ] Реализовать реестр запросов.
- [ ] Блокировать дублирующиеся operation ID.
- [ ] Проверять metadata: kind, risk, exposure, version.
- [ ] Валидировать вход по JSON Schema до вызова обработчика.
- [ ] Валидировать выход в тестовом режиме.
- [ ] Создавать контекст с `requestId`, `traceId` и `source`.
- [ ] Передавать `idempotencyKey` без самостоятельного хранения.
- [ ] Реализовать единый успешный конверт.
- [ ] Реализовать конверт ошибок и маппинг исключений.
- [ ] Поддержать cooperative cancellation через `AbortSignal`.
- [ ] Ограничить глубину вложенных команд.
- [ ] Обнаруживать циклы вложенных вызовов.
- [ ] Добавить unit- и integration-тесты.

## Контракты и зависимости

- Использует типы и конверты из KAN-002.
- Не реализует HTTP API.
- Не хранит idempotency-ключи в БД; передаёт ключ плагину.
- Не выполняет миграции и не публикует события.
- Не содержит определений конкретных команд.

## Критерии приёмки

- [ ] Команда регистрируется и выполняется через шину.
- [ ] Запрос регистрируется отдельно от mutation.
- [ ] Дублирующийся ID отклоняется при регистрации.
- [ ] Неверный вход не вызывает обработчик.
- [ ] Ошибка валидации имеет код `VALIDATION_ERROR`.
- [ ] Неизвестная операция возвращает `NOT_FOUND`.
- [ ] `source` и `requestId` доступны обработчику.
- [ ] `traceId` сохраняется во вложенных вызовах.
- [ ] Циклический вызов завершается ошибкой.
- [ ] Отмена через `AbortSignal` возвращает `CANCELLED`.
- [ ] Внутренние стектрейсы не попадают во внешний конверт.

## Проверки

## Риски

- Шина станет скрытым сервис-локатором. Разрешить только публичные операции и явный контекст.
- Двойная валидация схем. Использовать общий валидатор SDK.
- Неясная семантика отмены после записи. Не обещать откат уже закоммиченной операции.
