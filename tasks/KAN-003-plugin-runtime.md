# KAN-003 — Runtime и жизненный цикл плагинов

## Цель

Реализовать серверный runtime, который обнаруживает плагины, проверяет совместимость, разрешает зависимости и управляет их активацией без падения ядра.

## Результат

Ядро запускается с набором локальных плагинов, определяет корректный порядок активации и переходит в safe mode при ошибке отдельного плагина.

## Объём работ

- [x] Обнаружить манифесты в локальном каталоге плагинов.
- [x] Валидировать манифесты через Plugin SDK.
- [x] Проверять `hostApi` и версии зависимостей.
- [x] Строить граф зависимостей и отклонять циклы.
- [x] Реализовать топологический порядок активации.
- [x] Реализовать обратный порядок деактивации.
- [x] Блокировать дублирующиеся Plugin ID.
- [x] Реализовать состояния `failed`, `disabled`, `incompatible`, `safe_mode`.
- [x] Изолировать ошибки активации и деактивации.
- [x] Предоставить API состояния плагинов для plugin manager.
- [x] Реализовать минимальный формат диагностики.
- [x] Добавить тесты всех ошибочных переходов.

## Контракты и зависимости

- Использует типы и валидаторы из KAN-002.
- Не реализует команды, события, связи, миграции и UI.
- Не обращается к базе данных напрямую.
- Предоставляет lifecycle hooks, которые позднее использует runner миграций.

## Критерии приёмки

- [x] Плагин без зависимостей активируется первым.
- [x] Зависимый плагин активируется после зависимости.
- [x] Отсутствующая зависимость блокирует только зависимый плагин.
- [x] Цикл зависимостей обнаруживается с перечнем участников.
- [x] Несовместимый `hostApi` блокирует активацию.
- [x] Дублирующийся Plugin ID блокируется.
- [x] Ошибка активации не роняет ядро.
- [x] Деактивация выполняется в обратном порядке.
- [x] Safe mode содержит список проблемных плагинов и причины.
- [x] Состояние плагинов доступно без прямого чтения внутренних структур.

## Риски

- Runtime начнёт содержать доменную логику. Ограничиться lifecycle и реестром.
- Сложная система версий. Реализовать только диапазоны, требуемые Contract v1.
- Скрытая зависимость от порядка файлов. Проверять детерминированный порядок тестами.
