# KAN-003 — Runtime и жизненный цикл плагинов

## Цель

Реализовать серверный runtime, который обнаруживает плагины, проверяет совместимость, разрешает зависимости и управляет их активацией без падения ядра.

## Результат

Ядро запускается с набором локальных плагинов, определяет корректный порядок активации и переходит в safe mode при ошибке отдельного плагина.

## Объём работ

- [ ] Обнаружить манифесты в локальном каталоге плагинов.
- [ ] Валидировать манифесты через Plugin SDK.
- [ ] Проверять `hostApi` и версии зависимостей.
- [ ] Строить граф зависимостей и отклонять циклы.
- [ ] Реализовать топологический порядок активации.
- [ ] Реализовать обратный порядок деактивации.
- [ ] Блокировать дублирующиеся Plugin ID.
- [ ] Реализовать состояния `failed`, `disabled`, `incompatible`, `safe_mode`.
- [ ] Изолировать ошибки активации и деактивации.
- [ ] Предоставить API состояния плагинов для plugin manager.
- [ ] Реализовать минимальный формат диагностики.
- [ ] Добавить тесты всех ошибочных переходов.

## Контракты и зависимости

- Использует типы и валидаторы из KAN-002.
- Не реализует команды, события, связи, миграции и UI.
- Не обращается к базе данных напрямую.
- Предоставляет lifecycle hooks, которые позднее использует runner миграций.

## Критерии приёмки

- [ ] Плагин без зависимостей активируется первым.
- [ ] Зависимый плагин активируется после зависимости.
- [ ] Отсутствующая зависимость блокирует только зависимый плагин.
- [ ] Цикл зависимостей обнаруживается с перечнем участников.
- [ ] Несовместимый `hostApi` блокирует активацию.
- [ ] Дублирующийся Plugin ID блокируется.
- [ ] Ошибка активации не роняет ядро.
- [ ] Деактивация выполняется в обратном порядке.
- [ ] Safe mode содержит список проблемных плагинов и причины.
- [ ] Состояние плагинов доступно без прямого чтения внутренних структур.

## Риски

- Runtime начнёт содержать доменную логику. Ограничиться lifecycle и реестром.
- Сложная система версий. Реализовать только диапазоны, требуемые Contract v1.
- Скрытая зависимость от порядка файлов. Проверять детерминированный порядок тестами.
