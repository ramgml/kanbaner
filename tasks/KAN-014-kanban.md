# KAN-014 — Канбан

## Цель

Создать отдельный UI-плагин `kanbaner.kanban` с четырьмя фиксированными
колонками, перемещением карточек между статусами и изменением порядка.
Канбан использует тот же домен `kanbaner.tasks` и не содержит собственной
копии задач.

## Результат

- На `/view/kanban` открывается доска с колонками `Backlog`, `To do`,
  `In progress`, `Done`.
- Карточка показывает заголовок, приоритет, срок, теги и число подзадач.
- Перемещение доступно drag-and-drop и через меню/кнопки для клавиатуры и
  мобильных.
- Изменение оптимистично; при ошибке карточка возвращается, конфликт версий
  показывается без перезаписи.
- Порядок карточек сохраняется и переживает перезапуск.
- На мобильных колонки прокручиваются горизонтально.

## Контракты и зависимости

- Зависит от `kanbaner.tasks` (KAN-012) и UI-рантайма KAN-013.
- Новые контракты: UI-вклад `kanbaner.kanban.ui.v1`, маршрут `/view/kanban`.
- Использует команду `kanbaner.tasks.task.move` и запрос
  `kanbaner.tasks.task.list` через `@kanbaner/plugin-tasks/contract`.
- Не зависит от `kanbaner.task-list` в рантайме: детали рендерятся через
  общий `packages/task-ui`.

## Риски

- Drag-and-drop сложно сделать доступным. Смягчение: меню и кнопки — основной
  путь, DnD — дополнительный.
- Оптимистичное обновление может рассинхронизировать доску. Смягчение: откат
  по ошибке и повторный запрос после конфликта.
- Горизонтальная прокрутка на мобильных конфликтует со свайпами страницы.
  Смягчение: прокрутка только внутри контейнера колонок.
- Общий `task-ui` может разрастись. Смягчение: только переиспользуемые
  компоненты задач, без доменных запросов внутри библиотеки.
