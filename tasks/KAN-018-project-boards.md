# KAN-018 — Проекты как доски и сводки

## Цель

Добавить понятное отображение проектов: сетку досок с точными счётчиками и
переходами в канбан/список. Не вычислять сводки по пагинированным карточкам.

## Результат

- Пользователь видит проекты как карточки досок с описанием и состоянием.
- Для каждого проекта доступны точные счётчики backlog/todo/in_progress/done и
  просроченных задач.
- Открытие проекта ведёт на канбан с выбранным фильтром; доступен и список.
- Заголовок канбана использует ту же сводку без N+1.

## Критерии приёмки

- [ ] Счётчики точны и не зависят от текущей страницы карточек.
- [ ] Просроченные считаются по единому правилу.
- [ ] Карточка проекта открывает канбан и список с выбранным проектом.
- [ ] Сводка на доске совпадает с запросом и обновляется после команд.
- [ ] Все проверки зелёные.

## Проверки

- [ ] `pnpm check:imports`, полный `pnpm check`.

## Риски

- Агрегирование может потребовать полного чтения документов. Смягчение:
  инкапсулировать в Store; оптимизация отдельной задачей.
- Summary устаревает между командами. Смягчение: повторный запрос после
  успешных изменений.
