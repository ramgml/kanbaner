# KAN-018 — Проекты как доски и сводки

## Цель

Добавить понятное отображение проектов: сетку досок с точными счётчиками и
переходами в канбан/список. Не вычислять сводки по пагинированным карточкам.

## Результат

- Пользователь видит проекты как карточки досок с описанием и состоянием.
- Для каждого проекта доступны точные счётчики backlog/todo/in_progress/done и
  просроченных задач.
- Открытие проекта ведёт на канбан с выбранным фильтром; доступен и список.
- Заголовок канбана использует ту же сводку без N+1.
