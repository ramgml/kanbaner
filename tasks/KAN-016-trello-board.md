# KAN-016 — Trello-визуал канбан-доски

## Цель

Сделать доску визуально и по взаимодействию близкой к Trello: рабочая область,
серые списки, белые карточки, быстрый composer снизу колонки и понятный drop
placeholder. Домен и публичные операции не меняются.

## Результат

- Доска имеет полноценную рабочую область на высоту доступного пространства.
- Проект отображается как заголовок доски с описанием, без технического текста
  о домене и фиксированных колонках.
- Карточки компактные: заголовок, бейджи, срок, теги и подзадачи имеют ясную
  иерархию.
- Внизу каждой колонки можно быстро создать задачу по названию, не открывая
  полную форму.
- Место вставки при DnD видно между карточками.
- Мобильная версия сохраняет scroll-snap и даёт вкладки статусов для перехода.

## Объём работ

### Визуальная доска

- [x] Фон рабочей области на доступную высоту, мягкие нейтральные цвета,
  светло-серые списки, белые карточки с небольшой тенью.
- [x] Колонки около 272 px с гибким использованием десктопного пространства,
  аккуратные заголовки, счётчики и меню.
- [x] Убрать технический подзаголовок. Показывать название проекта и его
  описание; в режиме «Все проекты» — соответствующий агрегированный заголовок.
- [x] Карточка: заголовок главный, максимум два тега + `+N`, семантический срок
  (просрочено/сегодня/завтра/дата), число подзадач, компактное меню действий.
- [x] В режиме «Все проекты» показывать бейдж проекта на карточке.
- [x] Pending/conflict отображать индикатором без лишнего увеличения высоты.
- [x] Кнопки и меню остаются доступными с клавиатуры; мобильные hit targets не
  меньше 40 px.
- [x] DnD: placeholder между карточками и подсветка целевой колонки. Сохранить
  текущую полную область вычисления позиции.

### Быстрый composer

- [x] Заменить нижнюю кнопку колонки на Trello-like «+ Добавить карточку».
- [x] По активации показывать textarea с autofocus, кнопки «Добавить карточку»
  и закрытие.
- [x] `Enter` создаёт, `Shift+Enter` переносит строку, `Escape` закрывает.
- [x] Проект берётся из активного контекста, статус — из колонки, позиция —
  доменный append.
- [x] После успеха composer остаётся открытым для следующей задачи; новая
  карточка видна и переживает reload.
- [x] Двойной submit не создаёт дубль; ошибка сохраняет введённый текст.
- [x] Добавить действие «Добавить с деталями», открывающее существующую полную
  форму KAN-015.
- [x] Если проект не выбран, быстрый composer просит выбрать его и не теряет
  введённый заголовок.

### Мобильный режим и фильтры

- [x] Колонки сохраняют горизонтальную прокрутку и получают scroll-snap.
- [x] Вкладки статусов прокручивают к соответствующей колонке и показывают
  текущую.
- [x] Активные project/tag фильтры отображаются чипами с доступным сбросом.
- [x] Пустая колонка предлагает создать или перетащить задачу; пустой фильтр —
  сбросить фильтры.

### Проверки

- [x] Component-тесты карточек, composer, placeholder, вкладок и чипов.
- [x] E2E: быстрое создание нескольких задач подряд, Shift+Enter, Escape,
  выбор проекта, ошибка, double submit, DnD placeholder, mobile tabs, reload и

- [x] Все прежние E2E и проверки остаются зелёными; селекторы обновлять только

## Риски

- Изменение селекторов может сломать существующие E2E. Смягчение: сохранять
  стабильные data-testid там, где смысл элемента не изменился.
- Composer может нарушить видимость за page boundary. Смягчение: использовать
  существующие visibility requirements.
- Визуальная близость к Trello не должна копировать функции вне MVP:
  участников, activity, Power-Ups и пользовательские фоны не добавлять.
