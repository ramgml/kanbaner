# KAN-015 — Создание проектов и задач на канбане

## Цель

Добавить на канбан-доску создание проектов и задач без перехода в список.
Использовать существующие публичные команды `kanbaner.tasks` и общие формы
`packages/task-ui`, не дублируя доменную логику.

## Результат

- На панели доски доступны «Новый проект» и «Новая задача».
- В каждой колонке есть кнопка создания задачи с предустановленным статусом.
- При активном фильтре проекта он подставляется в форму автоматически.
- После создания карточка появляется в правильной колонке и сохраняется после
  перезагрузки.
- Формы работают с клавиатуры и на мобильных устройствах.

## Объём работ

- [ ] Добавить кнопки «Новый проект» и «Новая задача» на панель доски.
- [ ] Добавить кнопку создания в каждую из четырёх колонок.
- [ ] Использовать `ProjectForm` и `TaskForm` из `packages/task-ui`; расширять
      их только additively, если существующих полей недостаточно.
- [ ] Для создания задачи из колонки предустанавливать её статус и проект из
      активного фильтра; без фильтра требовать явный выбор проекта.
- [ ] Поддержать необязательного родителя только среди корневых задач выбранного
      проекта.
- [ ] Вызывать только `kanbaner.tasks.project.create` и
      `kanbaner.tasks.task.create` через `invoke`.
- [ ] После создания проекта обновить проекты и фильтры, не сбрасывая текущий
      выбор без необходимости.
- [ ] После создания задачи перечитать доску и догрузить целевую колонку до
      новой карточки. Использовать полный scope домена, а не видимую страницу.
- [ ] Не открывать форму вне `/view/kanban`; на мобильных использовать общий
      `ModalDialog` с focus trap, Escape и восстановлением фокуса.
- [ ] Блокировать повторную отправку во время запроса и не создавать дубль при
      двойном нажатии.
- [ ] Показывать ошибку внутри формы и сохранять введённые значения.
- [ ] Добавить component-тесты кнопок, предустановленных полей, submit, ошибок,
      повторного нажатия и появления карточки.
- [ ] Добавить E2E:
  - создать проект и сразу задачу в нём;
  - создать задачу через общую кнопку с выбором проекта и статуса;
  - создать задачи через кнопки колонок;
  - проверить активный фильтр проекта и тега;
  - проверить появление за границей уже догруженной страницы;
  - проверить отсутствие дублей при повторном нажатии;

## Владение файлами

Разрешено:

- `packages/plugin-kanban/**`;
- `packages/task-ui/**` — только additive изменения общих форм и dialog;
- `apps/web/e2e/kanban.spec.ts`, `apps/web/e2e/test-environment.ts` — только при
  необходимости;
- `tasks/reports/KAN-015.md`.

Запрещено:

- `packages/kernel/**`, `packages/plugin-sdk/**`, `packages/storage-sqlite/**`;
- `packages/plugin-tasks/src/**` и `packages/plugin-task-list/**`;
- `apps/web/src/**`, кроме явно необходимой additive интеграции;
- `specs/**`, другие плагины и файлы других задач.

Общие файлы:

- `packages/task-ui` используется совместно со списком; существующий API и
  поведение списка не должны сломаться.

## Контракты и зависимости

- Зависит от KAN-014 и публичных команд/запросов KAN-012.
- Новых доменных команд и изменений схем не требуется.
- Канбан по-прежнему импортирует только `@kanbaner/plugin-tasks/contract` и
  `packages/task-ui`.

## Критерии приёмки

- [ ] Проект и задача создаются без перехода в список.
- [ ] Кнопка колонки задаёт правильный статус; фильтр проекта учитывается.
- [ ] Новая карточка видна в правильной колонке и переживает перезагрузку.
- [ ] Повторное нажатие не создаёт дубликат.
- [ ] Ошибка не стирает введённые данные.
- [ ] Формы доступны с клавиатуры, фокус управляется корректно.
- [ ] На 360 px нет горизонтального overflow страницы.
- [ ] Канбан и список показывают согласованные данные.
- [ ] Прежние E2E остаются зелёными.

## Риски

- Новая карточка может оказаться за границей страницы. Смягчение: догрузка
  целевой колонки до созданного ID после команды.
- Общие формы могут регрессировать список. Смягчение: только additive API и
  прежние component/E2E-тесты.
- Повторная отправка может создать дубль. Смягчение: блокировка submit до
  завершения команды и тест двойного нажатия.
