# KAN-015 — Создание проектов и задач на канбане

## Цель

Добавить на канбан-доску создание проектов и задач без перехода в список.
Использовать существующие публичные команды `kanbaner.tasks` и общие формы
`packages/task-ui`, не дублируя доменную логику.

## Результат

- На панели доски доступны «Новый проект» и «Новая задача».
- В каждой колонке есть кнопка создания задачи с предустановленным статусом.
- При активном фильтре проекта он подставляется в форму автоматически.
- После создания карточка появляется в правильной колонке и сохраняется после
  перезагрузки.
- Формы работают с клавиатуры и на мобильных устройствах.

Разрешено:

- `packages/plugin-kanban/**`;

- `apps/web/e2e/kanban.spec.ts`, `apps/web/e2e/test-environment.ts` — только при
  необходимости;
- `tasks/reports/KAN-015.md`.

Запрещено:

- `packages/kernel/**`, `packages/plugin-sdk/**`, `packages/storage-sqlite/**`;
- `packages/plugin-tasks/src/**` и `packages/plugin-task-list/**`;
- `apps/web/src/**`, кроме явно необходимой additive интеграции;
- `specs/**`, другие плагины и файлы других задач.

  поведение списка не должны сломаться.

## Риски

- Новая карточка может оказаться за границей страницы. Смягчение: догрузка
  целевой колонки до созданного ID после команды.
- Общие формы могут регрессировать список. Смягчение: только additive API и
  прежние component/E2E-тесты.
- Повторная отправка может создать дубль. Смягчение: блокировка submit до
  завершения команды и тест двойного нажатия.
