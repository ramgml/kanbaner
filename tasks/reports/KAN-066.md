## Результат

### 1. Детерминированное название без вызова модели

- Новый модуль `packages/opencode/src/session-title.ts` содержит
  `DEFAULT_SESSION_TITLE = "Kanbaner chat"`, `SESSION_TITLE_MAX_POINTS = 60` и
  `deriveSessionTitle(text): string | null`.
- Пайплайн убирает fenced code, ссылки/изображения (оставляя label), HTML,
  script/style, комментарии, заголовки, списки, blockquote, checkbox,
  emphasis и inline code; нормализует Unicode (`toWellFormed`, U+FFFD),
  схлопывает пробелы и обрезает результат по границе слова с `…`.
- Название строится только из отображаемого текста запроса. Пустой текст,
  пунктуация и «шум» возвращают `null`, поэтому default title сохраняется.
- `createSession` использует ту же константу default title.

### 2. Server-side eligibility до prompt

- `OpenCodeGateway.ensureSessionTitle(sessionID, text, signal?)` добавлен в
  `types.ts` и реализован в `gateway.ts`.
- Проверки: abort, непустой derive, ownership/root/agent
  `kanbaner`/`metadata.source=kanbaner`/текущий project directory, title ровно
  `Kanbaner chat`, пустая canonical history через
  `message.list({ sessionID, limit: 1 })`.
- Мутация — только `session.update({ sessionID, title })`; `metadata`,
  permissions и прочие поля не передаются.
- Любая ошибка, ineligible-сессия и abort возвращают `null`; наружу ошибка не
  бросается и prompt outcome не меняется.
- Conditional rename в SDK отсутствует: гонка с ручным переименованием из
  другой вкладки остаётся last-write-wins.

### 3. Internal prompt transport

- `POST /api/opencode/session/{sessionID}/prompt` принимает optional bounded
  `titleText`: не более 2000 Unicode code points после ограничения первыми
  8192 UTF-16 units. Пустой/whitespace/non-string не вызывает ensure.
- Ensure выполняется после получения gateway и до `gateway.prompt`, с
  defensive catch; ошибка не отменяет prompt.
- При подтверждённом title response получает ASCII-header
  `x-kanbaner-session-title: encodeURIComponent(title)`. Без title header
  отсутствует. NDJSON, turn ID, admission/unconfirmed, redaction и прежние
  headers не изменены.

### 4. UI overlay и история

- UI отправляет `titleText` отдельно от `text` (display text без контекстной
  преамбулы и вложений).
- После успешного fetch header декодируется и сразу применяется к текущей
  generation/session: обновляются `session.title`, `titleOverridesRef` с
  `confirmedSeq` semantics и `historyVersion`.
- Stale canonical refresh не откатывает подтверждённый title; GET, начатый
  после подтверждения, принимает canonical title. Ручной rename продолжает
  работать, а повторный prompt не перезаписывает non-default title.
- Model overlay, status, drafts, attachments, unread и scroll semantics не
  изменены.

## Ограничения и риски

- SDK не предоставляет conditional rename: теоретическая гонка с ручным
  переименованием из другой вкладки остаётся last-write-wins.
- Ручной title, совпадающий с `Kanbaner chat`, неотличим от default.
- Детерминированная очистка не является полноценным CommonMark parser;
  экзотическая разметка может дать неидеальное название.
- Дополнительные preflight-запросы best-effort и не должны бросать ошибку
  наружу; это покрыто unit/integration-тестами, но live smoke первого prompt и
  ручного rename с настроенной моделью не выполнялся.
- Windows-специфичная проверка не запускалась: изменение не использует
  платформенные API или файловые пути.
