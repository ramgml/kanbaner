# KAN-033 — Подсказка с описанием карточки

## Что сделано

- Добавлен `CardDescriptionTooltip` с fixed portal-позиционированием поверх колонок.
- Hover мыши показывает описание через 400 ms; клавиатурный `focus-visible` —
  сразу, с `role="tooltip"` и `aria-describedby` у заголовка.
- Пустое описание и touch-hover не создают tooltip.
- Уход курсора/focus, Escape, scroll, resize, pointerdown, drag и открытие
  меню/карточки скрывают подсказку без перехвата событий других контролов.
- Markdown выводится как plain text целиком. Позиция выбирается выше/ниже
  карточки и ограничена viewport.
- На tooltip можно перевести курсор: задержка закрытия 150 ms позволяет перейти
  с карточки, а scroll внутри интерактивной области не закрывает её. Полное
  длинное описание прокручивается; layout и состав карточки не меняются.
