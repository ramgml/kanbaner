# KAN-056 — Resizable OpenCode-панель

Дата: 2026-11-20. Режим: текущий checkout, без worktree, коммита и push.

## Результат

- Правая OpenCode-панель на desktop получила resizable левую границу:
  Pointer Events + pointer capture, fallback на window при недоступном capture.
- Ширина: default 384 px, min 320 px, max 640 px. Максимум ужимается по
  `window.innerWidth` с резервом 640 px на левый sidebar и основное содержимое
  (`assistantMaxWidthFor`). При 1440 px максимум 640, при 1024 px — 384,
  при 900 px и ниже — 320.
- Ширина хранится в `kanbaner.opencode.panelWidth`; значение проверяется
  регуляркой/`Number.isSafeInteger` и clamp-ится. Исключения `localStorage`
  проглатываются: resize продолжает работать в памяти.
- Separator: `role="separator"`, `aria-orientation="vertical"`,
  `aria-valuemin/max/now`, `aria-controls`, `tabIndex=0`, ArrowLeft/ArrowRight
  (Shift — шаг 48), Home/End, double-click reset 384. Линия видна, есть
  hover/focus/dragging состояния, `cursor: col-resize`, `select-none`,
  `touch-none`.
- Desktop width задаётся inline style; на mobile inline width отсутствует,
  панель остаётся `w-full` fullscreen, resizer скрыт (`hidden md:block`).
- Open/close, восстановление `kanbaner.opencode.panelOpen`, focus на close и
  Escape не изменялись. Левый sidebar и его resizer не тронуты.

## Риски и ограничения

- Viewport clamp — эвристика с фиксированным резервом 640 px; фактическая
  ширина левого sidebar может быть 240–560 px, поэтому на узком desktop
  (768–900 px) основной контент может стать уже желаемого. Горизонтального
  overflow нет, клавиатура и drag остаются рабочими.
- Desktop определяется через `matchMedia("(min-width: 768px)")`; breakpoint
  синхронизирован с Tailwind `md` константой, но при смене брейкпоинта его
  нужно менять в двух местах.
- Полный `pnpm test`/`pnpm check` не запускался: по брифу выполнялись focused
  unit, typecheck, build и shell E2E. Windows-проверки не выполнялись.
- Коммит, merge, rebase и push не выполнялись; статус задачи оставлен
  `in_progress` до интеграции оркестратором.
