# KAN-054 — OpenCode assistant

Дата: 2026-11-19.

## Результат

Добавлен отдельный пакет `@kanbaner/opencode` с глобальной правой панелью чата,
catalog активных chat-моделей текущего OpenCode Service, session history,
model/variant switch и NDJSON streaming. На мобильном панель занимает весь
экран; по умолчанию она закрыта и не запускает Service.

OpenCode подключается через `Service.ensure()` и `@opencode/client@2.2.5`, не
через embedded SDK. Создаются и читаются только сессии агента `kanbaner` с
`metadata.source=kanbaner`. Prompt привязан к заранее созданному inbox ID и
`session.inbox.delivered`; предыдущее execution не завершает новый поток.
Отмена после admission выполняет `inbox.cancel` и `session.interrupt`.

Добавлен restricted `kanbaner-mcp`: project/task/note list/get/create/update,
task complete/move. Delete, shell и filesystem tools отсутствуют. Схемы строгие,
updates требуют `expectedVersion`, mutations получают instance-scoped
`Idempotency-Key`. Доменные вызовы идут только через Bearer-защищённый `/api/v1`.

## Независимые проверки

Два reviewer-агента проверили gateway/UI и MCP/config. Исправлены найденные
problems: terminal предыдущего execution, abort во время admission, потерянный
early HTTP abort, pagination cursor, abnormal NDJSON, mobile z-index/focus,
strict MCP input, process/instance idempotency scope, невалидный manifest и
расхождение `environment`/`codemode` в OpenCode V2 config. Финальное ревью не
нашло blocker/high; его medium/low замечания о pending refresh, stale ResourceRef,
abort+exception и Origin/Host также исправлены regression-тестами.
