# KAN-037 — Notion-подобный плагин заметок

## Что сделано

- Добавлен независимый `kanbaner.notes` с `/view/notes`, манифестом,
  client-safe contract, server activation и отдельным UI entrypoint.
- Реализованы дерево страниц, partial update с `expectedVersion`, move/reorder,
  защита от циклов и глубины, каскадное удаление, favorite/recent и поиск с
  полной переиндексацией.
- Визуальный Milkdown Kit редактор поддерживает CommonMark/GFM, toolbar,
  slash-действия, таблицы, ссылки, списки задач, code и изображения.
- Автосохранение сериализует команды, использует свежую версию после каждого
  ответа и сохраняет черновик при ошибке/конфликте. Конфликт можно скачать перед
  загрузкой серверной версии.
- Локальные PNG/JPEG/GIF/WebP хранятся отдельно от текста с проверкой base64,
  размера и сигнатуры. `attachment://` заменяется data URL в редакторе и экспорте;
  `.md` самодостаточен.
- Универсальные связи работают для notes/tasks/projects через `ResourceRef`.
  Добавлены generic resource opener, вложенные JSON slots и панель связанных
  заметок в задаче без импорта чужих плагинов.
- Общий безопасный renderer выделен в `@kanbaner/markdown-ui`.
- UI включает DnD и клавиатурные альтернативы, mobile 360, light/dark,
  breadcrumbs, favorites/recent/search и выбор родителя.

## Найденные и исправленные дефекты интеграции

- Дублирование AJV `$id` в source/target descriptor устранено фабрикой схемы с
  уникальным `createJsonObjectSchema()`.
- Пустой `search.reindex([])` больше не блокирует activation других плагинов.
- Tailwind сканирует `plugin-notes` и `markdown-ui`, поэтому responsive UI и
  visibility кнопок присутствуют в production CSS.
- Upload копирует живой `FileList` до reset input; добавлен regression test и
  production E2E. Без этого браузер очищал файлы до вызова команды.
- Поле связи использует input + datalist: задачи доступны подсказкой, произвольный
  ResourceRef не теряется при наличии tasks.
- Resource opener заменяет transit `resource` на канонический `note=<id>` после
  открытия; навигация внутри уже открытого `/view/notes` работает.
- Autosave запускается при unmount/pagehide/visibility hidden, поэтому SPA-уход
  не отменяет сохранение по debounce.
- Next Server Actions body limit согласован с 5 MiB attachments и base64.

## Ограничения и риски

- Runtime проверен в Chromium; Windows, Firefox и WebKit отдельно не запускались.
- Milkdown использует локальный declaration shim для NodeNext (`milkdown-kit.d.ts`);
  поведение проверяется настоящим пакетом и browser E2E, но shim требует
  сопровождения при обновлении зависимости.
- Визуальный serializer может нормализовать синтаксическое оформление Markdown;
  семантическое содержимое покрыто roundtrip fixtures.
- Нет trash, баз данных Notion, совместного редактирования и облачной синхронизации.
