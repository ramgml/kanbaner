# KAN-059 — Глобальный размер шрифта в настройках

Дата: 2026-11-23. Режим: текущий checkout, без worktree, коммита и push.

## Результат

- В `/settings` → «Оформление» добавлен native select «Размер шрифта» со
  значениями **90% / 100% / 110% / 125%**; по умолчанию 100%.
- Выбор сразу задаёт `document.documentElement.style.fontSize`, поэтому
  масштабируются Tailwind rem-размеры текста и связанных элементов.
- Значение сохраняется в `localStorage["kanbaner.ui.fontScale"]` и применяется
  на любом маршруте после reload/navigation.
- Статический bootstrap в `<head>` root layout восстанавливает значение до
  отрисовки и устраняет вспышку прежнего размера. `useSyncExternalStore`
  синхронизирует select после hydration без mismatch.
- Невалидные/неканонические значения и ошибки storage дают 100%; ошибка записи
  не отменяет текущее применение. Reset выполняется выбором 100%.
- Новых зависимостей, серверного хранения, автоопределения монитора и cross-tab
  синхронизации нет.

## Review

Независимый reviewer не обнаружил blocker/high, но нашёл medium: runtime
`Number(raw)` принимал `090`, `9e1`, `0x5a` и подобные значения, тогда как
bootstrap принимал только canonical allowlist. Worker убрал numeric coercion;
теперь разрешены только точные числа/строки `90`, `100`, `110`, `125`. Добавлены
негативные regressions на неканонические строки.
