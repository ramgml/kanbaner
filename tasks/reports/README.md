# Отчёты worker-ов

Worker создаёт один отчёт на задачу:

```text
tasks/reports/KAN-003.md
```

Отчёт является единственным файлом в `tasks/`, который worker может создать самостоятельно во время параллельной работы. Файл задачи и общий backlog изменяет только оркестратор.

## Формат

```markdown
# KAN-003 — Отчёт

- Задача: `tasks/KAN-003-plugin-runtime.md`
- Ветка: `feat/kan-003-plugin-runtime`
- Worktree: `.worktrees/kan-003-plugin-runtime`
- Коммит: `<sha>`

## Что сделано

Краткое описание результата.

## Изменённые файлы

- `path/to/file`

## Проверки

- `typecheck` — passed
- `lint` — passed
- `test` — passed

## Отклонения от плана

Что пришлось изменить и почему.

## Риски и ограничения

Что осталось незавершённым или требует внимания.

## Предложенные задачи

- Краткое описание будущей работы без назначения ID.
```

## Правила

- Не редактируй файл задачи.
- Не назначай ID новым задачам.
- Не скрывай красные проверки.
- Не заявляй о завершении задачи без коммита и проверок.
- Если задача заблокирована, укажи точный вопрос и необходимое решение.
