# KAN-042 — Понятный выбор проекта для связи заметки

## Итог

Ручной ввод `plugin:type:id` в блоке связей заменён на picker проектов и задач.
Пользователь открывает список, видит название и тип («Проект»/«Задача»), ищет по
названию и добавляет связь мышью или клавиатурой. `ResourceRef` остаётся
внутренним значением picker-а и в интерфейсе не показывается.

Существующие связи по-прежнему отображаются, открываются через `openResource` и
удаляются командой `note.unlink` с фактическими `sourceRef`/`targetRef`.
Публичные команды, схемы и формат `ResourceRef` не менялись.

## Изменённые файлы

- `packages/plugin-notes/src/ui/note-link-picker.tsx` — новый picker:
  - `project.list`/`task.list` через UI invoker, страницы по 100 элементов и
    «Показать ещё» по `nextOffset`;
  - поиск по названию без учёта регистра;
  - типы «Проект»/«Задача», loading/error/retry, empty state и «Ничего не найдено»;
  - клавиатура: ↑/↓/Home/End/Enter/Escape, `aria-activedescendant` и возврат
    фокуса на кнопку;
  - мобильная раскладка без абсолютного overlay: panel в потоке, список с
    `max-h-64` и вертикальной прокруткой.
- `packages/plugin-notes/src/ui/note-links.tsx` — input/datalist удалён,
  подключён picker; `note.link`/`note.unlink`, refresh, open/delete сохранены.
- `packages/plugin-notes/src/ui/note-link-picker.test.tsx` — unit-тесты picker-а:
  loading, empty, типы/поиск/no-results, клавиатура/Escape, ошибка и retry.
- `packages/plugin-notes/src/ui/note-links.test.tsx` — добавление связи с
  проектом по видимому названию и видимая ошибка создания связи.
- `apps/web/e2e/notes.spec.ts` — E2E: выбор проекта по названию через поиск и
  Enter, открытие связи, удаление; no-results; mobile 360 без overflow. Старый
  сценарий с ручным `ResourceRef` удалён.
- `packages/plugin-notes/README.md` — описание выбора связи по названию.

## Риски и ограничения

- Поиск выполняется по загруженной странице (100 проектов и 100 задач). Более
  дальние записи доступны через «Показать ещё», но автоматической догрузки по
  поисковому запросу нет: публичный `project.list` не поддерживает `text`, а
  серверный поиск задач не смешивается с клиентским списком проектов.
- Picker, как и прежний UI, умеет связывать только проекты и задачи. Связи с
  заметками и другими ресурсами, созданные ранее, продолжают отображаться,
  открываться и удаляться, но выбрать новый такой ресурс из этого блока нельзя:
  задача KAN-042 ограничивает picker проектами и задачами.
- Встроенный shadcn `Command`/`Combobox` не используется: в `apps/web` нет
  компонента `command`, а `plugin-notes` не может импортировать внутренности
  приложения и не должен добавлять новую component library. Picker реализован на
  существующих React, Tailwind-токенах и lucide-иконках.
- E2E проверяет мобильный viewport без overflow, но не измеряет размеры touch
  target на реальном устройстве.
