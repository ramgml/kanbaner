# KAN-019 — Рабочее пространство проектов

## Цель

Объединить пользовательские представления в один плагин `kanbaner.projects`:
переключение проектов в sidebar, канбан конкретного проекта, список задач,
переключатель представления и создание карточки только по названию.

Домен `kanbaner.tasks`, хранение и публичные команды не меняются. Отключение
UI-плагина не влияет на данные и API.

## Результат

- Sidebar содержит проекты с поиском, выбором и созданием, а не постоянные
  пункты администрирования.
- Канбан всегда принадлежит одному проекту. Агрегированная доска всех проектов
  и бейдж проекта на карточках удалены.
- Заголовок проекта содержит переключатель `Список / Канбан` с сохранением
  проекта, фильтров и выбранной задачи.
- Создание карточки требует только название; проект определяется доской,
  статус — колонкой, полная форма открывается только для редактирования.
- Текущие Trello-доска, модал, composer, список и сводки продолжают работать в
  одном UI-плагине.

## Риски

- Большой перенос может потерять часть старого поведения. Смягчение: перенос
  тестов вместе с кодом и сохранение routes/test IDs.
- Sidebar может быть перегружен большим числом проектов. Смягчение: поиск,
  внутренний scroll и последний активный проект.
- Удаление старых plugin ID меняет состав plugin manager, но не данные. Это
  фиксируется в отчёте и проверяется отключением.
