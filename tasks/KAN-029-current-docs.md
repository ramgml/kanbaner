## Цель

Устранить расхождения документации с текущим plugin-ядром, доменом и UI, а также
зафиксировать согласованные изменения меню, редакторов, иконок и цветов.

## Результат

- Корневой README описывает текущее приложение, а не каркас KAN-001.
- Команды разработки и границы пакетов соответствуют `package.json`.
- Доменный README содержит массовые команды.
- Спецификации используют `kanbaner.projects` и фиксируют новые UX/цветовые
  решения без утверждения, что они уже реализованы в коде.
