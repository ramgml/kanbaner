# KAN-007 — UI shell и plugin manager

## Цель

Создать адаптивный каркас интерфейса с базовыми слотами и экраном управления плагинами, не добавляя доменной логики.

## Результат

Пользователь видит пустой shell, навигацию, состояние плагинов, ошибки активации и может отключить проблемный плагин.

## Объём работ

- [ ] Реализовать адаптивный app shell на Next.js 16 App Router.
- [ ] Подключить Tailwind CSS 4 и shadcn/ui с Radix UI preset.
- [ ] Использовать Lucide React как единый набор иконок.
- [ ] Реализовать слоты `app.sidebar`, `app.main`, `app.details`, `app.settings`, `app.overlays`.
- [ ] Реализовать клиентский реестр UI-вкладов.
- [ ] Реализовать маршрутизацию представлений плагинов.
- [ ] Добавить границы ошибок для UI-плагинов.
- [ ] Реализовать экран plugin manager.
- [ ] Показать версии, зависимости, состояние и последние ошибки.
- [ ] Реализовать включение и отключение плагина.
- [ ] Реализовать отображение safe mode.
- [ ] Обеспечить клавиатурную навигацию.
- [ ] Обеспечить мобильную раскладку от 360 px.
- [ ] Добавить component- и integration-тесты shell.

## Владение файлами

Разрешено:

- `apps/web/**`;
- тесты UI внутри `apps/web/**`.

Запрещено:

- `packages/kernel/**`, кроме публичного API, уже предоставленного KAN-003;
- `packages/plugin-sdk/**`;
- `specs/**`;
- `tasks/**`, кроме собственного отчёта;
- реализации задач, заметок, канбана и поиска.

Общие файлы:

- Корневой `package.json` и конфигурация UI-инструментов изменяются по координации с оркестратором.
- API plugin manager должно использовать публичный интерфейс ядра, а не импортировать его внутренности.

## Контракты и зависимости

- Использует UI-метаданные и Plugin SDK из KAN-002.
- Использует состояние плагинов из KAN-003.
- Использует Tailwind CSS 4, shadcn/ui и Radix UI согласно `specs/technology-stack.md`.
- Не добавляет вторую component library и не создаёт собственный design system.
- Не реализует собственные доменные представления.
- Не обходит lifecycle и не активирует плагин в обход ядра.

## Критерии приёмки

- [ ] Shell открывается без активных доменных плагинов.
- [ ] Плагин регистрирует тестовый UI-вклад через публичный API.
- [ ] Ошибка рендера вклада показывается локально и не роняет shell.
- [ ] Plugin manager показывает актуальное состояние плагинов.
- [ ] Отключение плагина отражается без перезагрузки всей страницы или объясняет необходимость перезагрузки.
- [ ] Safe mode объясняет причину и показывает проблемные плагины.
- [ ] Навигация доступна с клавиатуры.
- [ ] На ширине 360 px основные действия доступны.
- [ ] В shell нет импортов доменных плагинов.
- [ ] В интерфейсе нет встроенного ИИ или AI-настроек.
- [ ] В `apps/web` нет второй component library помимо shadcn/ui.

## Риски

- UI-контракт зафиксируется слишком жёстко. Реализовать только слоты Contract v1.
- Plugin manager начнёт напрямую управлять внутренним состоянием. Использовать публичный API ядра.
- Ошибка одного плагина сломает страницу. Обязательные error boundaries на каждый вклад.
