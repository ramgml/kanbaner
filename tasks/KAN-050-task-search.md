# KAN-050 — Поиск по задачам

## Цель

Дать пользователю быстро находить задачи по названию и описанию в списке и на канбане.

## Результат

В обоих представлениях проекта есть поле поиска. Оно использует существующий `task.list.text`, комбинируется с фильтрами, сохраняется в query string и при переключении Список/Канбан, очищается явно и через сброс фильтров.

## Объём работ

- [ ] Добавить `q` в query-state списка и канбана.
- [ ] Добавить доступное поле поиска с Lucide Search, кнопкой очистки и debounce без потери вводимого текста.
- [ ] Передавать `text` в task.list, сбрасывать страницу списка и корректно перезагружать колонки канбана.
- [ ] Покрыть unit/integration и E2E поиск, комбинацию фильтров, URL и переключение представлений.

## Владение файлами

Разрешено:

- `packages/plugin-projects/src/**` только для search UI/query-state и тестов;
- `apps/web/e2e/task-list.spec.ts`, `apps/web/e2e/kanban.spec.ts`;
- `specs/product-mvp.md` при необходимости уточнения поведения;
- `tasks/reports/KAN-050.md`.

Запрещено:

- изменение `plugin-tasks`, SDK, хранилища и операций: `task.list.text` уже реализован;
- новый отдельный search plugin или новые зависимости.

## Контракты и зависимости

Существующий `task.list.text` ищет подстроку без учёта регистра по NFKC title/descriptionMarkdown. Все остальные фильтры комбинируются по AND. Изменение доменного контракта не требуется.

## Критерии приёмки

- [ ] Поиск находит задачу по title и descriptionMarkdown, не зависит от регистра.
- [ ] Неподходящие карточки/строки скрываются; пустой результат отображается корректно.
- [ ] Поиск сочетается с tag/priority/column и сбрасывает страницу списка.
- [ ] `q` переживает reload и переключение Список/Канбан; reset очищает его.
- [ ] Существующие создание, выбор, drag-and-drop и пагинация не ломаются.
