# Kanbaner

Локальная веб-система управления задачами и заметками, построенная как минимальное plugin-ядро.

Канбан, список задач, заметки, поиск и интеграция с внешними агентами являются плагинами. Ядро отвечает только за загрузку расширений, команды, события, хранение, UI-слоты и HTTP API.

## Ключевые принципы

- Локальная однопользовательская установка без регистрации и аккаунтов.
- Plugin-first: доменные функции поставляются как плагины и используют публичный SDK.
- Домен задач отделён от представлений: канбан и список зависят от `tasks`, а не наоборот.
- Плагины взаимодействуют через версионированные команды, запросы и события.
- Встроенного ИИ нет. Внешние агенты подключаются через HTTP API и необязательный MCP-адаптер.
- Плагины считаются доверенным локальным кодом. Текущая модель не является песочницей.
- Данные хранятся локально; облачная синхронизация не требуется.
- Внешний сервер БД, Docker и TCP-порт не требуются.
- MVP работает на Linux и Windows.
